# Product

## Register

product

## Users

Individual developers running several coding agents and local services on one Mac, often while working in an editor or terminal and needing a fast operational view without cloud setup.

## Product Purpose

Local Observer is a local-first command center for discovering, understanding, and managing local development activity. It brings running servers, coding-agent sessions, token usage, provider quota windows, source health, and integration settings into one trustworthy native macOS interface.

## Brand Personality

Calm, exact, trustworthy. The interface should feel focused during active development, legible at a glance, and clear about uncertainty rather than presenting guesses as facts.

## Anti-references

Do not resemble generic AI dashboards, neon terminal interfaces, oversized metric-card grids, or marketing-style usage reports. Avoid decorative charts, invented metrics, excessive card nesting, and provider-specific visual exceptions that break the shared system.

## Design Principles

1. Show the operational answer first, then preserve enough context to verify it.
2. Make source, freshness, and uncertainty visible whenever usage data is incomplete.
3. Keep server and agent concepts separate while making their relationships understandable.
4. Prefer familiar native and Notion-like interaction patterns over novelty.
5. Add capability only when it supports the user's monitoring and management workflow.

## Accessibility & Inclusion

Meet WCAG AA where applicable, support reduced motion, preserve keyboard access, maintain readable contrast, and never use color as the only indicator of status.
